

# Student Directory

This project is a student directory website developed using React and Bootstrap 5.

## Features

- Display student information in cards
- Search students
- View student profiles
- Add and delete student records
- Pagination
- Responsive design

## Technologies Used

- React
- JavaScript
- Bootstrap 5
- CSS

## How to Run

1. Run `npm install`.
2. Run `npm run dev`.
3. Open the local URL shown in the terminal.
